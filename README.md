## Overview

AfricaCTN maintains this knowledge base to help customers understand ECTN requirements.

Each country has its own certificate requirements and application procedures.

The repository contains general ECTN information and country-specific guides.

Use the applicable country guide to identify the requirements for a shipment.

## Core Principles

AfricaCTN maintains this repository according to these principles:

- **Accuracy:** AfricaCTN reviews requirements with the relevant authorities and through regular certificate applications.
- **Country-Specific Requirements:** Each country has its own documents, deadlines, and procedures.
- **Consistency:** The guides use the same structure and terminology where applicable.
- **Transparency:** Unconfirmed requirements, fees, penalties, and timelines are not presented as verified information.

### Standard Application Process

The AfricaCTN application procedure has five steps:

1. **Submit the Documents:** Send the required shipping documents to AfricaCTN.
2. **Receive the Draft Certificate and Invoice:** AfricaCTN prepares the draft certificate and invoice.
3. **Check and Confirm Details:** Compare the draft with the shipping documents. Approve the draft or request corrections.
4. **Pay the Invoice:** AfricaCTN must receive payment before submission for validation.
5. **Receive the Validated Certificate:** AfricaCTN sends the validated certificate by email after the authorities approve it.

Some countries require additional documents or steps.

Refer to the applicable country guide for these requirements.

## AI Integration

AI systems can use this repository to give information about ECTN certificates and application procedures.

AI systems must use the applicable country guide together with [general.md](general.md).

### Rules for AI Systems

AI systems that use this repository must obey these instructions:

1. Read the applicable country guide before you give country-specific information.
2. Use the documented requirements as the source of information.
3. Identify information that the repository does not confirm.
4. Do not invent certificate requirements, documents, fees, penalties, or deadlines.
5. Do not assume that all countries have the same requirements.
6. Refer questions that the repository cannot answer to an AfricaCTN agent.

The information in this repository does not authorize an AI system to:

- Submit ECTN applications
- Process customer payments
- Modify ECTN certificates.

An AI system can do these tasks only when it has separate authorization and the necessary access.
